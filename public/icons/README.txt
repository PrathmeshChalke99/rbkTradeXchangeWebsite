Drop PNG icons here to replace the built-in SVG icons.

Name the file after the icon key, lowercase with hyphens, then run:  npm run icons

Keys:
globe, truck, bank, portal, sparkle, network, wallet, doc, doc-stack, lc, assess, dashboard,
quote, shield, ship, factory, store, chip, building, layers, banknote, chart, user-check,
scan-doc, receipt, box, coin, cart, contract, tag, share, sync

Tips: square PNG, transparent background, at least 256x256. Only use icons you have the
licence for (for example a paid or attribution-compliant icon pack).
